# 交通

## 1. 数据从哪来（按优先级）

| 要查 | 先用 | 再用 | 注意 |
|---|---|---|---|
| 机票 | 飞猪 `flyai search-flight` | 途牛 `tuniu call flight …`（国内）/ `intelflight`（国际） | 途牛 **5 次/分钟、50 次/天**，调用之间 `sleep 13`，一轮 ≤4 次 |
| 火车 | 12306 MCP（余票、经停、中转） | 飞猪 `search-train` 补充 | 12306 只放 15 天内的票，超窗口怎么办见 `train-booking` |
| 市内路线、时长、票价 | 高德真实路线 `amap-route.mjs` / `map-widget` 的 `real_route`（见 `travel-maps`） | `amap-gui route`（只有文字步骤） | — |
| 外币价格 | `convert_to_cny` 换成人民币 | — | 标"约合人民币 ¥xx" |

所有价格都是**查询参考价**，写明查询日期；**不代订**，只给预订入口。

## 2. 飞机还是高铁：比门到门，不比飞行时长

- **算门到门时间**：出门 → 到机场/车站 → 安检候机（国内航班至少提前 1.5 小时）→ 飞行/乘车 → 落地出站 → 进城。机场离市区远的城市（成都天府机场离市区约 70 km、地铁 80–90 分钟），进城时间要算进去。
- **算首末日能玩多少**：早班机能让第一天下午就开始玩；晚班机能让最后一天玩满。这往往比票价差更值钱，在方案里写成一句结论（"飞过去不到 3 小时，比高铁快 8 小时还便宜近一半"）。
- **廉航要写清行李额**：春秋等不含免费托运、手提 7 kg，两个人带箱子要另加钱——给出加托运后的价格，或给一个含托运的替代航班。
- **深夜落地**：写清地铁末班时间，落地后怎么回家/去酒店（打车或夜班车）。
- 多个候选航班/车次列成表，标"推荐"并说一句为什么。

### 大交通要写的信息

- **航班**：航班号 / 起降**三字码** / 航站楼 / 当地起降时间 / 历时 / 行李额 / 参考价。
- **火车**：车次、出发/到达站名、席别、历时、参考价。
- **PNR 与订单号留空，标「预订后回填」**——你不代订，本来就不该有这些号。

## 3. 市内交通：每一段都选定一种方式，并写清怎么走

这是行程能不能落地的关键，别含糊。

- **公共交通（地铁/公交）**：线网密、准点、便宜，适合景点在地铁沿线。**必须写清"坐几号线 → 哪站换乘 → 哪站下 → 几号口出 → 末班时间"**，不能只写"乘地铁前往"。票价按真实路线查到的值写。
- **开车（打车/自驾）**：景点分散、公交稀、赶时间、带老人小孩时选它。
  - **打车费必须估出来并计入预算**：起步价 + 里程单价 × 实测公里数（距离从真实路线拿）。
  - 自驾另算**租车费 / 油费（或电费）/ 停车费 / 过路费**；电车要查沿途和住处的充电桩（`amap-gui searchPOI --keyword 充电桩 --center … --radius …`）。
  - **打车等待时间不计入行程时间**（用户要求）；**打车费用一定要计入**。
- 每天行程里逐段写明，例如"地铁 1 号线 → 王府井站 C 口出，步行 5 分钟"或"打车约 6 km ≈ ¥25"。

## 4. 时长与费用：用真实路线，不要估

- **市内每一段都用高德真实路线**：地图组件写 `"real_route"` 时，组件会把每段的里程、耗时、票价、乘坐的线路写进地图下的清单——**行程正文和预算里的市内交通直接用这些数**。单独查一段用 `amap-route.mjs`（命令见 `travel-maps`）。
- **按导航时间 ×1.5 计门到门**（补找路、候车、买票、排队）。
- 不要写"约 10–15 分钟"这种估算；实在查不到才估，并标"估算"。

## 5. 自检

- 飞机/高铁的取舍是按门到门时间比的吗？首末日可玩时间算了吗？
- 机票/火车都是本次查询的参考价、写了查询日期、落在用户预算内吗？廉航行李额写了吗？
- 市内每一段都选定了方式并写清怎么走（几号线、几号口，或打车公里数与费用）？打车/自驾费计入预算了吗？
- 市内时长与票价来自真实路线，而不是估算？深夜落地、末班车提醒了吗？
